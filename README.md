# Standing Desk Store
Static React + Vite + Tailwind product page, Stripe Payment Link checkout, fulfilled via CJdropshipping (SKU CJJT2319201, US warehouse).
- `npm run build` → `dist/` deployed to the `gh-pages` branch.
- `fulfillment/stripe-to-cj.mjs` — turn a paid Stripe checkout session into a CJ order (dry run by default).
